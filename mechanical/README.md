# Mechanical

Frame, mounts and case parts for the network drone.

Put CAD source files (STEP, and the native files from whatever CAD tool you use) here, plus a STEP export of the flight controller board (KiCad PCB editor: File → Export → STEP) so the frame can be designed around it.

Key board dimensions: 36 mm wide, 39 mm tall, four M2 holes on a 20 × 20 mm pattern, 8 mm in from the left, right and bottom edges and 11 mm from the top. Nothing on the top side sits within 3 mm of a hole centre and the bottom near the holes is bare, so the grommets that come with the ESC (or an M2 nut) fit on either side.
