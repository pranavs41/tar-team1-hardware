# Mechanical

Frame, mounts and case parts for the network drone.

Put CAD source files (STEP, and the native files from whatever CAD tool you use) here, plus a STEP export of the flight controller board (KiCad PCB editor: File → Export → STEP) so the frame can be designed around it.

Key board dimensions: 36 × 36 mm, four M2 holes on a 20 × 20 mm pattern centred on the board.
